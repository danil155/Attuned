# Attuned

Веб-сервис, решающий проблему неэффективного поиска контента в игровой индустрии. Существующие решения в открытых интернет-источниках часто ограничены рамками одного сервиса распространения компьютерных игр или поверхностными тегами. Данное решение предлагает пользователю возможность подобрать потенциально интересные для него проекты, основываясь на его предпочтениях.

---

## </> Технологический стек

### **Backend**
* **Язык:** Python 3.10
* **Фреймворк:** FastAPI (Uvicorn)
* **БД:** PostgreSQL 17 (SQLAlchemy)
* **Векторный поиск:** pgvector

### **ML (Math)**
* **Embeddings:** HuggingFace TEI (`all-MiniLM-L6-v2`)
> `all-MiniLM-L6-v2` - processor-friendly модель. Может быть заменена на `intfloat` или подобные при развертке на видеокарте.

### **Frontend**
* **Фреймворк:** React 19+
* **Сборка:** Node.js 20

### **Инфраструктура и DevOps**
* **Оркестрация:** Docker / Docker Compose
* **Reverse Proxy:** Nginx (manual HTTPS with SSL termination, WebSocket & SSE-ready)
